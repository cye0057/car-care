# 车管家管理台 · UI/UX 重设计方案

> 依据 make-ui-ux-better 规范输出 ｜ 应用类型：SaaS 管理后台 ｜ 目标用户：门店管理员/运营人员（专业用户，桌面优先）

## 1. 执行摘要

对现有骨架做「设计系统化 + 品牌化 + 响应式」三层改造：建立以 CSS 自定义属性为核心的设计令牌（颜色/间距/圆角/阴影/动效），支持浅深色双主题；统一导航布局为可折叠侧栏 + 顶栏面包屑的成熟后台范式；列表页收敛出统一的页头/工具栏/空状态规范；动效克制（120-240ms，尊重 reduced-motion）。不引入新 UI 库，基于 Element Plus 主题变量做覆盖，保持毕设代码可控。

## 2. 响应式策略

- **断点**：≥1440px 大屏（内容区居中 max-width 1280px）/ ≥1024px 桌面（标准侧栏）/ 768–1023px 平板（侧栏自动收起为图标栏）/ <768px 手机（侧栏变为抽屉，顶栏汉堡按钮唤出；工具栏自动换行；表格横向滚动）
- **桌面优先**：管理后台主战场是 PC，移动只做「查看与轻操作」；触控目标最小 40×40px
- 表格列在移动端保持原样横向滚动（不做卡片化重构，成本控制）；表单弹窗 <768px 全屏化

## 3. 性能蓝图

- 路由懒加载（已具备）；Element Plus 按当前全量引入保持不变（毕设规模 <2.5s LCP 可达，构建期可换 unplugin 按需引入，列为后续优化项）
- 动画仅用 transform/opacity（GPU 合成），避免 layout 抖动；侧栏折叠宽度过渡使用 `cubic-bezier(.4,0,.2,1) 240ms`
- 字体：系统字体栈，不加载 webfont；图标使用 @element-plus/icons-vue（内联 SVG）

## 4. 设计系统规范（Design Tokens）

**色彩（浅色主题）**
- 品牌主色 `--cc-primary: #2563eb`（可靠近 Element 蓝但更沉稳）；辅助色 success `#16a34a` / warning `#d97706` / danger `#dc2626` / info `#64748b`
- 中性色阶：内容背景 `#f6f8fb`、卡片 `#ffffff`、主文字 `#0f172a`、次文字 `#64748b`、占位/边框 `#e2e8f0`
- 侧栏深色固定：`#0f172a → #1e293b` 渐变

**色彩（深色主题）**：背景 `#0b1220`、卡片 `#151e31`、文字 `#e2e8f0`、边框 `#273349`，主色提亮为 `#3b82f6`；通过 `html.dark` 切换并映射 Element 暗黑变量

**间距**：8px 基准（4/8/12/16/24/32）；页面内边距 24px（移动端 16px）；卡片内边距 20px

**圆角**：卡片 12px、按钮沿用 Element、标签 6px、弹窗 16px

**阴影**：两级 elevation——卡片 `0 1px 2px rgba(15,23,42,.06)`，悬浮/弹层 `0 8px 24px rgba(15,23,42,.12)`

**排版**：H1 20/600、H2 16/600、正文 14、辅助 12；数字展示使用 tabular-nums；统计卡数值 28/700

## 5. UX/UI 模式规范

- **反馈**：所有异步操作 loading 态（v-loading/按钮 loading）；删除/状态变更必须确认；成功轻提示 2s
- **导航**：面包屑 + 当前菜单高亮；折叠侧栏仅图标 + tooltip；用户菜单含退出与主题切换
- **空状态**：表格统一 `empty-text`，首次无数据文案「暂无数据，点击右上角新建」
- **表单**：即时校验 + 提交前校验双保险；数字输入统一右对齐、金额显示千分位与 ¥ 前缀
- **动效**：页面切换 fade-slide 240ms；hover 仅位移 2px 与阴影加深；提供 `prefers-reduced-motion` 降级
- **可访问性**：主题切换/汉堡按钮带 aria-label；focus-visible 保留；文字对比度 ≥ 4.5:1

## 6. 技术架构调整

- 新增 `src/styles/tokens.css`（令牌与 Element 变量映射、深浅主题）、`src/styles/base.css`（布局工具类、滚动条、动效）
- 主题状态入 Pinia 并持久化 localStorage；新增 `useTheme` composable
- Layout 重写：el-container + 折叠菜单 + 移动端抽屉；Login 重写：左品牌区右表单卡片，移动端隐藏品牌区
- Dashboard 重写：渐变描边统计卡 + 今日订单列表
- 列表页模式不变（保留已验证的 CRUD 逻辑），仅统一套入页头样式

## 7. 分阶段落地

- **M1 本次**：令牌/主题/布局/登录/工作台/列表页视觉统一
- **M2**：阶段5 车主端复用同一套 tokens（Vant 定制主题）
- **M3**：图表看板（ECharts）与暗色下对比度复查

## 8. 质量清单

- [ ] 320/768/1024/1440 四档无横向溢出（表格容器除外）
- [ ] 暗色主题下所有文字对比度达标、无白底残留
- [ ] 侧栏折叠/展开动画流畅无跳位
- [ ] 路由守卫、401 跳登录逻辑不回归
- [ ] reduced-motion 开启后无大幅动画
